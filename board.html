Embedded Linux Project

ATK-IMX6U 项目

记录板卡上的 Linux、Qt/QML、硬件接口与远程调试实践。设备地址、登录方式和临时公网入口仅在受控环境中维护，不在公开站点发布。

私有维护通道

设备调试、SSH 登录和 IO 控制台仅通过私有网络访问，具体地址与凭据保存在本地运维文档中。

  • 远程维护私有组网
  • 本地调试电脑直连
  • 访问控制仅授权设备

公开页面不提供可点击的设备入口，避免临时链接失效或控制面暴露。

临时分享原则

确需演示时，使用带身份验证和有效期的临时通道，并通过单独渠道发送入口。

  • 身份验证必须启用
  • 有效时间按需开启
  • 入口地址不公开留存
  • 结束演示立即关闭

不要在 Git 仓库、公开网页或聊天记录中长期保存有效入口和访问凭据。

控制台功能

板子首页现在是 IO 与系统状态控制台，适合在浏览器里直接观察硬件和运行状态。

  • 输出控制sys-led、beep
  • 输入显示GPIO Key 实时事件
  • 传感器AP3216C 环境光、红外、接近检测
  • RTC 时间rtc0 时间、系统时间、时间偏差
  • 系统状态CPU、温度、内存、磁盘、运行时间
  • 网络状态eth0 路由器、eth1 电脑直连
