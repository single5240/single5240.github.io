# 博客改造：实现与验证记录

日期：2026-10-17。设计依据见 [调研方案](blog-redesign-research-2026-10-17.md)。

## 已实现

- 首页重排：简短介绍、精选文章、项目演示、最新笔记、专题、日常入口。首屏不再使用全屏插画布局。
- 新增文章归档、四个有实际内容的专题、日常聚合、关于和 404 页面，保留原文章、英语、资讯和项目演示地址及首页 `#top`、`#articles`、`#daily-reading`、`#contact` 锚点。
- 新增技术文章标题/摘要/全部标签搜索、专题组合筛选、结果状态、空结果与清除操作，查询条件可通过 URL 分享。索引失败时回退页面文本；无 JS 时保留列表与专题。
- 统一 default/frame/article 公共外壳及导航数据；文章样式、目录和代码操作拆到独立资源。正文提供桌面侧目录、手机折叠目录、代码语言与复制反馈、表格横向滚动、文章与项目关联。
- 项目页使用独立 SVG 界面示意及清晰的模拟边界，演示脚本仅在项目演示页加载；模拟器算法、记录及校正逻辑未改动。
- 英语归档与日常页使用公共模板。六篇现有 AI 日报保留独立 HTML，统一返回导航并通过 data-mode 共享颜色偏好；来源块保留。
- 日报重复导入保持稳定，不再累积插入空白；保留原始 Liquid 字面文本和无 front matter 契约，加入回归测试。
- Pages 工作流构建、检查成功后上传产物，再由依赖作业发布。PR 只检查。Pages 后台必须采用 GitHub Actions 发布源，不能继续依赖默认分支构建。

## 验证证据

- WSL Ruby/Bundler 的真实 Jekyll 构建，而非模拟 Liquid 输出；严格 front matter 构建与站点检查。
- 10 个共享浏览器/维护脚本通过 Node 语法检查；日报导入回归测试通过。
- 浏览器：360、390、768、1366 宽度；首页、归档、QML 长文、项目索引、日常、英语详情、AI 日报、Linux 专题、关于共 9 类页面；深浅主题共 72 个组合，均无整页横向溢出，各页一个 h1。屏宽是浏览器模拟，不等于真机触摸验收。
- 搜索 DMA 命中 1 篇；与 Qt 专题组合得到空结果；清除后恢复 7 篇。目录生成 30 个条目，对应 QML 长文的 30 个 h2/h3；58 段代码均有复制按钮，实点复制反馈为「已复制」。
- 主题菜单支持方向键定位、Escape 关闭并恢复焦点、跟随系统；AI 日报模式选择与主站主题双向衔接。
- 拉力计演示现有自检 51/51 通过；手机浏览器模拟输入 2 N 正常显示，清除与 MENU 操作正常，无整页横向溢出。本次未修改模拟器逻辑，未重新做完整六点校正、记录删除及真机测试，不将网页测试等同硬件验证。
