## 2. 声学工程标准与防尖锐失真底线

全类别声音合成均遵守严格的声学物理防线：

1. **零直角破音 (Zero Hard Click)**：
   所有击键、敲击、水滴与脉冲均由 `linearRampToValueAtTime` 软淡入上升沿（3~8ms）包裹，根除数字突波。
2. **严苛的高频钝化天花板 (Dynamic LPF Rolloff)**：
   主总线串联两级级联 `BiquadFilterNode`，默认截止频率锁定在 1200Hz~2200Hz，彻底消除 4kHz~12kHz 的尖锐金属哨鸣与齿音。
3. **安全限幅防爆音 (Soft Limiting)**：
   Master Bus 搭载专用 `DynamicsCompressorNode`（Threshold -6dB, Ratio 12:1, Attack 0.003s），防止极端参数叠加大动态削波。
4. **3Dio 假人头空间物理真实度**：
   通过左右独立声相调制、微时间延迟（ITD）与微响度差（ILD），模拟真实 17cm 头宽耳距。

## 3. 全局多主题与响应式布局架构

1. **五大主题完美支持**：
   - 默认深色 (Dark)
   - 默认浅色 (Light)
   - 瑞士设计网格 (Swiss)
   - 深空终端 (Terminal)
   - 极简单色 (Mono)
2. **响应式 10 大分类切换网格**：
   - 大屏/桌面端：5 列双行对称网格（2 行 x 5 列），视觉对称饱满。
   - 移动端/平板端：自动折叠为两列，按钮保持足够点击热区与无障碍聚焦。
3. **Canvas 2D 独立渲染引擎**：
   支持「沉浸拟物粒子 (Scenic)」、「3Dio 空间雷达 (Radar)」与「极简休眠暗光 (Minimal)」三大视觉模式，每帧重置物理变换矩阵，适配 Retina/高分屏 DPR 缩放。
