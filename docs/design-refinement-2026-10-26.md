# 网站视觉与交互优化

日期：2026-10-26。

保留青绿色、工程网格、示波器与机器人；让首页负责介绍与体验，归档负责检索，长文负责安静阅读。

## 调整

- 首页以阅读笔记和体验项目为主要入口；统计改为一行辅助信息，Skills 数量来自集合。精选拉力计与声音实验室，其余项目通过“继续探索”进入。手机隐藏仪器装饰并压缩首屏。
- 归档搜索前置，文章列表使用轻量分隔；匹配文字高亮，关键词与专题分别清除，文章返回链接恢复搜索条件。保留 URL 分享、索引失败回退及无 JavaScript 列表。
- 文章标题与正文取消重面板，目录先于机器人；桌面伴读工作台按需打开。普通文章与日常卡片不再随鼠标倾斜。
- 项目目录增加类型与两篇精选笔记，完整清单按需展开；技能预览图移除易过期的数量。
- 修复首页 CRC、HardFault、RGB565 快捷锚点；工具定位使用当前位置语义并遵循减少动态效果偏好。
- 声音实验室播放、音量和定时前置；声学微调与提示词按需展开。没有改变音频引擎、初始参数或混音布局。
- 首页波形可暂停；减少动态效果时不自动轮换波形；文章与手机不弹出悬浮机器人。状态时钟准确标为北京时间，避免暗示真实设备健康监测。

## 验证入口

1. `bundle exec jekyll build --strict_front_matter`
2. `node scripts/check-site.mjs`
3. 递归对 `assets/js/**/*.js` 运行 `node --check`，并运行 `git diff --check`。
4. `node scripts/check-design.mjs`：需要可用的 Playwright；可通过 `PLAYWRIGHT_MODULE` 指定模块位置，`PLAYWRIGHT_CHANNEL` 选择浏览器，`DESIGN_SCREENSHOTS` 保存截图。
5. `node scripts/check-asmr-mixer.mjs`：沿用相同 Playwright 环境设置。

设计回归覆盖首页、归档、长文、项目、工具及声音实验室，360/390/768/1440px、浅深主题共 48 组；检查标题唯一、整页溢出、脚本错误、搜索组合/特殊字符/返回状态、工具定位、折叠面板和暂停入口。

混音回归覆盖 390/1280/1920/2560px 下展开面板不改变主区宽度，114 个音频变体、4,490 次瞬态淡入、四轨操作与资源回收。浏览器模拟不等于手机真机验收；本轮没有重新评价真实耳机听感或进行性能提升测量。
