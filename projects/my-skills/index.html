新建 Skill 标准模板 (_templates/skill-template)

每个 Skill 将内容分开放置：SKILL.md 说明触发条件、操作步骤和检查项，长篇寄存器表与代码范例放入 references/ 与 examples/：

---
name: template-skill-name
description: >-
  [Scope: global | vendor | project] 用第三人称简明描述该技能的用途与触发条件。
---

多工具同步脚本 (sync-skills.ps1)

利用 Windows 目录联接（Junction mklink /J）将各分类目录下的 Skill 挂载到 Codex、Cursor、Claude Code 与 Antigravity：

$Categories = @("common", "mcu-baremetal", "rtos", "linux-driver", "protocols-debug")
$TargetToolDirs = @(
  (Join-Path $env:USERPROFILE ".codex\skills"),
  (Join-Path $env:USERPROFILE ".cursor\skills"),
  (Join-Path $env:USERPROFILE ".agents\skills"),
  (Join-Path $env:USERPROFILE ".claude\skills")
)
# 遍历包含 SKILL.md 的子目录并创建 Junction 联接
cmd /c mklink /J "$linkPath" "$sourcePath" | Out-Null
