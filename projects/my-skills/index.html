4. 仓库目录架构、预留方向与按需挂载配置

AGENTS.md · skills.json · sync-skills.ps1

除已上线的三大方向外，中心库还预留了 rtos/（FreeRTOS / ThreadX / RT-Thread / Zephyr）与 linux-driver/（设备树 DTS / 字符与总线驱动 / U-Boot / Yocto）两个一级方向，以及标准的 _templates/skill-template 模板与跨工具一键同步脚本。

目录树与五大技术方向

一级目录按技术栈边界划分，内部通过 global / vendor / project / experimental 四个 Scope 区分复用层级：

mySkills/
├── AGENTS.md              # 全局规则与维护指南
├── README.md              # 技能库总览与接入说明
├── skills.json            # 根级技能注册清单
├── sync-skills.ps1        # 多 Agent 目录联接同步脚本
├── common/                # 通用与工程基建 (5 skills)
├── mcu-baremetal/         # 单片机裸机开发 (8 skills)
├── protocols-debug/       # 通信协议与硬件联调 (3 skills)
├── rtos/                  # 实时操作系统 (FreeRTOS/ThreadX)
├── linux-driver/          # Linux 驱动与设备树 (DTS/BSP)
└── _templates/            # 新建 Skill 标准骨架模板

在其他项目中按需挂载 (skills.json)

新建 Skill 标准模板 (_templates/skill-template)

每个 Skill 遵循渐进式披露原则：SKILL.md 聚焦触发条件、核心流程与安全门禁清单，长篇寄存器表与代码范例放入 references/ 与 examples/：

---
name: template-skill-name
description: >-
  [Scope: global | vendor | project] 用第三人称简明描述该技能的用途与触发条件。
---

# <Skill 标题名称>
## 1. 适用范围与背景 (Metadata)
## 2. 核心执行流程 (Step-by-Step Workflow)
## 3. 关键安全与并发约束检查清单
## 4. 验证与调试方法 (Verification)

多工具一键同步脚本 (sync-skills.ps1)

利用 Windows 目录联接（Junction mklink /J）将五大目录下的所有 Skill 自动挂载到 Codex、Cursor、Claude Code 与 Antigravity：

$Categories = @("common", "mcu-baremetal", "rtos", "linux-driver", "protocols-debug")
$TargetToolDirs = @(
  (Join-Path $env:USERPROFILE ".codex\skills"),
  (Join-Path $env:USERPROFILE ".cursor\skills"),
  (Join-Path $env:USERPROFILE ".agents\skills"),
  (Join-Path $env:USERPROFILE ".claude\skills")
)
# 遍历包含 SKILL.md 的子目录并创建 Junction 联接
cmd /c mklink /J "$linkPath" "$sourcePath" | Out-Null
