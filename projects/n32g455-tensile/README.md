# 数显式拉力计 界面演示

> 上次修改：2026-10-11 11时（北京时间）

这是一个**纯本地网页**，用来演示拉力计在 240×320 屏幕上的界面与操作。
不需要联网、不需要安装任何东西、不需要服务器。

## 怎么打开

**双击 `index.html`** 即可（推荐 Chrome / Edge / Firefox 的较新版本）。

如果双击后是空白页，通常是浏览器安全设置挡住了本地脚本，两种解决办法：

1. 换用 Chrome 或 Edge 打开；或
2. 在本文件夹里起一个极简本地服务（需要装过 Python）：
   ```
   python -m http.server 8080
   ```
   然后浏览器访问 `http://127.0.0.1:8080/`。

## 发给客户时怎么打包

整个 `html` 文件夹一起压缩即可，**不要把 `index.html` 单独拿出来发**——
它需要旁边的 `js` 文件夹。压缩包内应保持这个结构：

```
html/
├── index.html          ← 入口，双击这个
├── README.md           ← 本说明
└── js/                 ← 17 个脚本（含点阵字库），必须与 index.html 一起
```

在 Windows 里：右键 `html` 文件夹 → 发送到 → 压缩(zipped)文件夹。

## 界面怎么操作

屏幕右侧和下方是**演示控件**，它们不属于产品画面，只用来代替真实传感器和按键。

### 模拟力值

| 控件 | 说明 |
| --- | --- |
| 右侧竖向滑块 | **向上拖 = 拉伸（正力值），向下拖 = 压缩（负力值）**，中点是 0。顶端是当前量程的满量程，底端是负满量程 |
| 松开滑块 | 约 300 毫秒回到 0 —— 这一"回落"正是完成一次峰值测试的动作 |
| 力值输入框 + 保持 | 按**当前显示单位**输入数值，回车或点"保持"后力值就固定在这个读数上（方便观察峰值、公差、校正采点）。正数为拉伸，负数为压缩 |
| 清除 | 结束保持，力值回到 0 |
| 超出量程 | 自动钳位到正负满量程，并在输入框下方提示 |

### 五个按键

短按即可；带"长按"的键需要按住到指定时间。

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| **MENU** | 主界面进菜单 / 菜单回主界面 / 设定页回菜单 | 与短按相同 |
| **UNIT** | 上一项（菜单、设定页）；编辑时减一档 | 按住 **2 秒**循环显示单位（g → kg → N → lb） |
| **ZERO** | 去皮、清曲线、清峰值（力值超过满量程 20% 时不执行） | 与短按相同 |
| **DATA** | 请求保存；菜单/设定页下一项；记录页翻页 | 首页按住 **2 秒**进入记录清单；松手后在清单内重新按住 **5 秒**进入清空确认 |
| **PWR** | 菜单进入当前项；设定页进入编辑 / 确认 | 与短按相同 |

### 两个开关

| 开关 | 说明 |
| --- | --- |
| 接点 | 代替接点输入信号，用于"接点保持"动作 |
| 朝向 | 只在"屏幕方向 = 自动"时生效，打开后画面转 180° |

## 页面里能看到什么

- 主界面：电量、时间、实时/峰值模式、大字号力值、单位、峰值与双结果、波形曲线、底部动作名与公差判定（`OK` / `-NG` / `+NG`）。
- 菜单与四个设定页：基本设定、系统设定、通信设定、存储设置（含只读展示项）。
- 记录清单：每页 5 条，支持翻页、排序、时间显示开关、清空。
- 校正系统：密码、量程与方向选择、六点采集、放弃确认、结果。
- 右下角"自检结果"和右侧"运行状态"：演示自检信息，**客户演示时可以直接忽略**。

## 说明与限制

- 本页是**界面与交互演示**，力值由滑块或输入框给出，**不是真实计量校准结果**。
- 设置、单位、记录和完整校正点保存在浏览器本地（localStorage），刷新后仍在；密码授权只在本次页面运行期间有效。想恢复出厂状态：在浏览器里清除本站数据，或换个浏览器/无痕窗口打开。
- 浏览器切到后台时页面刷新会被系统节流，松手回零的手感会变慢。演示时保持页面前台。
- 部分设定项（采样频率、地域重力、自动息屏、荷重上限、正负显示、图表方向、关机功能、连接速率、数据位等）在演示页里**只改显示值并记住**，不接入测量——这与固件里"可改但不驱动测量"的行为一致。

## 测试与校正的操作顺序

在基本设定选择“峰值”，再选择测试动作。默认起始值为 0.2 N，输入载荷后保持至少 200 ms；可先用 2 N / −2 N 练习。

- 压缩：输入负值，保持后清除载荷。
- 拉伸：输入正值，保持后清除载荷。
- 插拔：先输入负值，再输入正值，然后清除；只有一个方向时结果不完整。
- 接点保持：接点先关闭，输入正值启动，再打开接点，最后清除载荷。
- 破断：输入正值启动，再明显回落或清除；回落确认后继续采集 300 ms，MAX/FB 保持锁定。

完成后短按 DATA 保存。有效 ZERO（载荷不超过 20% FS）清除结果并允许下一次测试；仅点击演示控件“清除”是卸载，不会清掉已完成的结果。

校正系统输入密码 0000，选量程和方向，从 0%、20%、40%、60%、80%、100% 逐点输入稳定载荷并按 PWR 采集。校正期间控件按待选量程输入，但产品量程仍保持旧值。第六点保存成功后新量程和该方向校正点一起生效；同量程保留另一方向并共享零点，换量程使另一方向失效。取消或写入失败保留旧参数。保存后的六点五段曲线参与测量换算，因此校正时应按目标值加载。
