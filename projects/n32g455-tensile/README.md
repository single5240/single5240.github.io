# 数显式拉力计界面演示

> 上次修改：2026-10-16 19时（北京时间）

纯本地 240×320 交互演示，按当前固件提交 `229dbea` 的可见行为同步。页面接入站点导航与主题切换，请通过站点打开，或在仓库根目录运行 `bundle exec jekyll serve` 后访问 `/projects/n32g455-tensile/`。脚本仍为普通 `<script>`，不依赖 ES module。

## 操作

- 滑块向上为正向拉伸，向下为负向压缩；松手约 300 ms 回零。
- 输入框按当前单位输入，点击“保持”固定载荷；“清除”卸载，ZERO 清除已完成结果并允许复测。超过 20% FS 时 ZERO 不执行去皮。
- MENU 进入/返回菜单；UNIT/DATA 上下移动；PWR 进入/编辑/确认；UNIT 按住 2 秒循环单位。
- 首页 DATA 按住 2 秒进入记录清单。清单内重新按住 5 秒进入清空确认。
- 清单 PWR 进入单条选择，UNIT/DATA 跨行、跨页移动；PWR 进入删除确认，再按 PWR 删除，MENU 取消。删除后保持邻近选择，删除末页唯一记录时退回前页。

## 当前同步内容

- 基本设定：六档背光 100/88/76/64/52/40%，立即改变演示屏亮度；传输速度移至通信末项，固定 100 Hz。
- 系统设定：简体中文、英文、台湾繁体中文；波形显示开关。语言表和字库从当前固件自动提取。
- 主页：左上时间、右上电量，移除方向箭头；数值固定右对齐。峰值模式突出测试结果、次行显示实时值；关闭波形后改为上下分区的大字布局。
- 公差：按当前量程的 ±FS 设置有符号窗口，步长 0.1 N，边界算 OK。荷重上限固定 100% FS，不再提供可编辑菜单项。
- 地域重力：默认 9.807 m/s²，参与 g/kg/lb 显示和演示输入的逆换算。2 kg、5 kg 量程主页 g 单位保留两位小数。显示死区进入 0.05% FS、退出 0.1% FS。
- 测试：压缩、拉伸、插拔、接点保持、破断、按键六种动作；结果完成后可手动或自动保存。记录页保留三位起的连续展示序号、排序和时间开关。

## 按键测试

基本设定选“峰值 → 按键”，再选 Fp、Fp/Fc、Fp/Fr、Fp/Cc、Fp/Cr。按键下压为负向压缩。

“演示按键曲线”是屏幕外的演示控件：切换至按键动作并输入一条固定模拟曲线，供观察完整识别。成功后可短按 DATA 保存。曲线为下压 → Fp → Fc → 压到底 → 释放谷值 Fr → 回弹 → 回零。示例 Fp = −2 N、Fc = −1.2 N、Fr = −0.6 N，Cc = 40%、Cr = 70%。只下压再直接回零不保证有效，缺少释放突跳会显示 ERR。

算法按固件 v2 的暂行行业剖面转写：8 点确认、50 ms 振铃屏蔽、Fr 的 8 点中 5 点命中、无 Fr 回零 20 ms、阶段 4 秒和总计 10 秒超时。网页将帧间的模拟输入重采样到约 2402 Hz，每帧最多补 100 ms；这不是实际 ADC 采样。

## 双层校正

密码 0000；先选量程，再选大量程/小量程层，然后选拉伸/压缩。

- 大量程六点：0/20/40/60/80/100% FS。
- 小量程六点：0/4/8/12/16/20% FS。
- 每点稳定至少 200 ms 后按 PWR 采集。六点合法且浏览器存储写入成功才提交。
- 同量程保留其他曲线，大量程双向共享零点；切换量程清除旧量程曲线。取消或写入失败保留旧数据。
- 有大曲线和小曲线时，按小曲线形状展开为 26 点、25 段；仅有大曲线时使用五段。密码授权不跨页面运行保存。

## 演示边界

设置、校正与记录保存在 localStorage，兼容旧页面字段；没有新增字段时使用当前默认值。旧记录可继续查看。浏览器空间不足时写入失败并保留原数据。

页面使用模拟 ADC、浏览器帧调度和本机日历。背光为 CSS 亮度效果；存储仅模拟用户可见保存/删除/清空，不复刻 W25Q128 的 V2/V3 二进制格式、扇区迁移和掉电恢复。输入仍钳位在 ±FS，不能用控件直接演示真实过载。浏览器后台节流不代表固件时序。

采样频率、自动息屏、正负显示、图表方向、关机与通信参数保留展示/编辑范围；未接入真实硬件。固件的 1/10/100 ms 分级调度、LCD 条带 DMA、PWM、DAC、RTT 和 Flash 维护不在网页中虚拟实现。
