过去找界面或品牌灵感，习惯打开几个综合大图库漫无目的地刷瀑布流，结果往往是装饰性的“概念图”看了一堆，真正落地到导航栏怎么折叠、首屏信息层级怎么排、弹窗无障碍交互怎么写、品牌手册怎么定目录时，却找不到可直接参照的真实样本。

近年来设计圈明显转向**“垂直切片 + 人工精选”**：把庞大的设计问题拆解成极细的颗粒度——只收导航栏的画廊、只录 60fps 真实 App 动效的视频库、只索引上线品牌规范的档案馆、只收真实 X/Twitter 产品宣传帖的灵感墙。按工作流把这些高密度网站串起来，查找参考的效率会成倍提升。

本文以一套常用的 15 个核心设计书签为骨架，按**“整体网页画廊 → 局部区块与组件系统 → App 交互流与动效 → 品牌规范与演示文稿 → 每日精选聚合 → 视觉背景、字体与素材库”**六大类别展开，并为每一类补充经过实测筛选的同类型优质站点，最后附带按项目阶段直接调用的组合路线。

> **阅读索引说明**：每个分类中，带 `⭐` 标记的是核心基础清单站点，其余为按场景互补的同类精选资源；全篇共收录 88 个独立站点，均优先指向官方 HTTPS 入口。

## 一、网页灵感画廊与落地页精选（Web Galleries & Landing Pages）

做产品官网、个人主页或活动落地页时，最先需要确定的是**信息密度、网格比例与视觉氛围**。这一类画廊专门收集已经真实上线的优秀网页，适合在项目立项初期快速拉齐审美基准。

### 1.1 极简、单页与全品类标杆画廊

- ⭐ **[Minimal Gallery](https://minimal.gallery/)**（`minimal.gallery`）：专注极简主义风格网站的经典灵感画廊。收录站点的共同特征是克制留白、严谨的字体层级与干净的网格秩序，不靠花哨特效撑场面；站内同时整理了一批精选的 Framer 与 Webflow 模板，适合直接对标轻量化产品页与个人作品集。
- ⭐ **[A1 Gallery](https://a1.gallery/)**（`a1.gallery`）：每日更新的高质量综合网页画廊，亮点在于**分类极为齐全**——按 Landing、Portfolio、AI、Studio、SaaS、E-commerce 等标签细粒度检索，覆盖从科技初创到创意工作室的各类风格，适合按业务赛道快速找参考。
- ⭐ **[One Page Love](https://onepagelove.com/)**（`onepagelove.com`）：深耕单页网站（One-Page）与落地页的老牌数据库。不仅能按行业和风格看真实单页案例（含个人简历、活动页、小型 SaaS 产品发布页），还整理了大量专题合集（如 Bento 布局专场）以及单页模板目录。

### 1.2 同类优质网页画廊补充

- **[Curated.design](https://curated.design/)**（`curated.design`）：兼具“风格标签”与“页面区块”双维度筛选的网页灵感库。支持 `⌘K` 快捷检索，除了按 Minimal、Dark、Brutalist、Gradients 等风格过滤，还能直接定位某类网页的 Hero、Pricing 或 Footer 区块。
- **[Land-book](https://land-book.com/)**（`land-book.com`）：偏重商业落地页与营销官网的精选库，收录站点普遍具有清晰的价值主张、成熟的社会认同与转化路径，非常适合做实用型 SaaS 或独立开发者产品官网对标。
- **[Saaspo](https://www.saaspo.com/)**（`saaspo.com`）：专门服务 SaaS 与科技产品的官网库，最大优势是**按具体页面类型归类**——不仅看首页（Landing Page），还能单独查看定价页（Pricing）、产品功能页（Product）、集成生态页（Integrations）和关于页（About）。
- **[Dead Simple Sites](https://deadsimplesites.com/)**（`deadsimplesites.com`）：比 Minimal Gallery 更进一步“做减法”的合集，专收彻底剥离滚动劫持与装饰性动效、只靠纯正排版、留白与高对比度说话的极简网页，适合为过度堆砌特效的项目做审美降噪。
- **[Dark.design](https://www.dark.design/)**（`dark.design`）：专注暗色模式（Dark Mode）网页的垂直画廊。如果你的产品面向开发者工具、AI 基础设施或硬核硬件，需要拿捏深灰层级与光影微弱高光，这里比综合站省时得多。
- **[Lapa Ninja](https://www.lapa.ninja/)**（`lapa.ninja`）：长期维护的落地页长截图画廊，直接以整页纵向预览展示完整叙事节奏，同时附带免费图标、配色和着陆页模板索引。
- **[SiteInspire](https://www.siteinspire.com/)**（`siteinspire.com`）与 **[Seesaw](https://seesaw.website/)**（`seesaw.website`）：SiteInspire 历史悠久、偏出版物与创意机构调性，支持多维度交叉过滤；Seesaw 则是每日更新的清爽数字体验画廊，亮点是支持**按网页使用的字体（Typeface）反查案例**。
- **[Awwwards](https://www.awwwards.com/)**（`awwwards.com`）与 **[The FWA](https://thefwa.com/)**（`thefwa.com`）：行业评审级互动网页奖项风向标，适合用来摸清 WebGL、3D 渲染、空间叙事与品牌大站创意表现的行业上限（日常做实用产品页时注意控制实现复杂度）。

## 二、页面区块切片与 UI 组件系统（Sections, Components & Design Systems）

确定整站基调之后，实际动手往往卡在具体模块：导航栏太长怎么收、首屏 Hero 怎么摆图文比例、复杂下拉选择器在不同成熟设计系统里究竟叫 `Combobox` 还是 `Select`。下面这组站点专治“局部结构拿不准”。

### 2.1 首屏、导航与跨系统组件档案

- ⭐ **[Supahero](https://supahero.io/)**（`supahero.io`）：专门收集网站首屏（Above-the-fold Hero 区）的灵感库，定位为 “UX Asset Library”（与移动端界面库 Screens Design 同源联动）。因为只聚焦首屏第一屏，非常便于对比各家大标题字号比例、副标题长度、CTA 按钮数量以及右/背景视觉锚点的排布规律。
- ⭐ **[Navbar Gallery](https://navbar.gallery/)**（`navbar.gallery`）：专门研究网站导航设计的垂直画廊，细致覆盖顶部导航栏（Navbar）、大型下拉菜单（Mega Menu）、侧边栏（Sidebar）与顶部公告条，支持按结构类型、视觉风格以及 Framer / Webflow 技术栈筛选。
- ⭐ **[The Component Gallery](https://component.gallery/)**（`component.gallery`）：目前最好用的**跨设计系统 UI 组件索引**之一。它把 Shopify Polaris、Ant Design、Atlassian Design System、Elastic UI 等数十套知名设计系统的组件（如弹窗 Modal、下拉菜单 Dropdown、选项卡 Tabs、组合框 Combobox、徽章 Badge 等）按组件类别聚合在一起：
  - 可以直接横向对比不同大厂对同一组件的命名差异（比如是叫 Tag、Chip 还是 Lozenge）；
  - 每个系统条目都会标明技术栈（React、Vue、Web Components、Tailwind CSS 等）、开源与无障碍支持情况，并直链官方文档、GitHub 源码与 Storybook 实例，查完结构就能顺藤摸瓜看代码实现。

### 2.2 其余页面区块与可复用前端组件库

- **[Footer.design](https://footer.design/)**（`footer.design`）：与 Navbar Gallery 上下呼应，专门收录网页页脚（Footer）的灵感库，里面单独归类了暗黑页脚、极简页脚以及近年流行的 Bento 网格页脚。
- **[BentoGrids](https://bentogrids.com/)**（`bentogrids.com`）：专门收集“便当盒（Bento Box）”不对称模块化网格布局的画廊，做产品特性九宫格、硬件参数概览或数据仪表盘卡片时能直接找到精妙的尺寸拆分比例。
- **[CTA.gallery](https://cta.gallery/)**（`cta.gallery`）：聚焦行动号召（Call-to-Action）区块的小众精选站，适合推敲页尾转化栏的文案钩子、按钮对比度与配图搭配。
- **[Landingfolio](https://www.landingfolio.com/)**（`landingfolio.com`）：除了整页截图外，还把官网拆成 Hero、Features、Pricing、FAQ、Testimonials 等组件区块，部分提供现成的 Tailwind CSS 与 Webflow 组件片段。
- **[Design Systems Surf](https://designsystems.surf/)**（`designsystems.surf`）与 **[Design Systems Repo](https://designsystemsrepo.com/)**（`designsystemsrepo.com`）：如果你需要从全局了解各家设计系统的 Design Token 分层、色彩阶梯与文档结构，这两个索引站和 Component Gallery 配合起来非常顺手。
- **直接落地的代码级组件生态**：
  - **[Radix UI](https://www.radix-ui.com/)**（`radix-ui.com`）：提供无样式、严格遵循 WAI-ARIA 无障碍规范与键盘导航的底层交互原语（Dialog、Popover、Dropdown 等）。
  - **[shadcn/ui](https://ui.shadcn.com/)**（`ui.shadcn.com`）：基于 Radix UI + Tailwind CSS 的源码复制式组件集合，已经成为现代 React 前端界面审美与工程架构的事实基准。
  - **[21st.dev](https://21st.dev/)**（`21st.dev`）：围绕 React / Next.js / Tailwind 生态的开源 UI 区块与交互组件社区注册表，支持按 Hero、Bento、Carousel 等直接复制或通过 CLI 接入。
  - **[Aceternity UI](https://ui.aceternity.com/)**、**[Magic UI](https://magicui.design/)**、**[React Bits](https://reactbits.dev/)** 与 **[Uiverse](https://uiverse.io/)**：前三个主打面向高视觉表现力的动画区块与交互特效（粒子、光束、文字揭示、Shader 背景等），Uiverse 则汇集了大量社区贡献的纯 CSS / Tailwind 轻量按钮、加载态和开关控件。

## 三、App 交互流、界面录屏与微动效灵感（App Flows & Motion）

静态截图只能看清长相，真正的产品体验往往藏在**手指点下去之后那几百毫秒的弹性阻尼、页面过渡以及从引导到支付的连贯状态流**里。

### 3.1 真实 App 动效录屏基准

- ⭐ **[60fps.design](https://60fps.design/)**（`60fps.design`）：专门收录主流线上 App（例如 ChatGPT、Duolingo、X 等）真实高帧率界面动效录屏的灵感库。支持按具体应用和交互类型（转场、手势、卡片展开、加载反馈等）筛选——相比凭空想象动画曲线，直接拆解头部应用是如何处理 60fps 阻尼、模态弹出和微反馈的，是最快的移动端动效训练方式。

### 3.2 用户旅程录屏、微交互与动效工具链

- **[Mobbin](https://mobbin.com/)**（`mobbin.com`）：目前全球规模最大的真实产品 UI/UX 截图与交互流数据库，完整覆盖 iOS、Android 与 Web 端主流应用。做原型前想看几十款成熟 App 的注册引导（Onboarding）、权限弹窗、空状态、支付墙或深色模式，直接上 Mobbin 按流程（Flows）或页面模式（Patterns）搜就行。
- **[Page Flows](https://pageflows.com/)**（`pageflows.com`）：老牌**完整用户旅程录屏库**（原专注移动端截图与录屏的 Screenlane 已并入并跳转至此）。它强调按“用户完成某一任务”的完整录像归档，能看清每一步点击前后的页面跳转与微提示，不仅限于孤立截图。
- **[Refero](https://refero.design/)**（`refero.design`）：侧重 Web 应用与 SaaS 界面的真实模式参考库，检索颗粒度极细，可以直接筛选 404 页面、定价表、侧边栏、空状态、表格过滤条等生产级细节。
- **[ScreensDesign](https://screensdesign.com/)**（`screensdesign.com`）：主攻高变现能力 iOS 应用的界面与流程拆解，特点是会关联应用的大致营收体量，适合结合商业转化视角研究付费墙（Paywall）与订阅流设计（与 Supahero 同属一套生态）。
- **[Design Spells](https://designspells.com/)**（`designspells.com`）：专门收集“让人眼前一亮的设计魔法细节”，比如藏在角落的趣味彩蛋、极具手感的物理回弹、有巧思的加载动画与 404 交互，用短 GIF / 视频呈现，非常适合给枯燥的功能页注入温度。
- **[Codrops](https://tympanus.net/codrops/)**（`tympanus.net/codrops`）：前端创意与实验动效老牌阵地，几乎每个视觉惊艳的页面滚动、Shader 扭曲、WebGL 转场教程都会附带可运行的开源代码仓库。
- **[Eyecandy](https://eyecannndy.com/)**（`eyecannndy.com`）：如果你还需要做产品宣传视频或品牌动画，这里把大量高水准影像按运镜手法（Match Cut、Snorricam、Datamosh 等）与动画风格拆成切片，是极佳的动态视觉词典。
- **动效落地实现工具**：代码侧可用 **[Motion（motion.dev）](https://motion.dev/)** 做声明式物理弹簧交互；需要跨平台复杂矢量状态机交互（比如开关小人、交互式插画）可选 **[Rive](https://rive.app/)**；要把 Figma 设计稿快速做成产品发布演示片或轻量 Lottie，可配合 **[Jitter](https://jitter.video/)** 与 **[Lottielab](https://www.lottielab.com/)**。

## 四、品牌重塑、官方规范、Logo 档案与演示文稿（Branding, Guidelines & Decks）

做品牌升级、软件视觉改版或撰写产品对外介绍 PPT 时，只看单张 Logo 远远不够，真正决定气质一致性的是**图形符号逻辑、规范手册结构、动态发布叙事以及幻灯片的信息节奏**。

### 4.1 品牌规范、重塑案例、Logo 与 Deck 四件套

- ⭐ **[Logobook](https://logobook.com/)**（`logobook.com`）：全球经典单色标志（Logo）与几何符号档案馆，页面极简克制，支持按字母、基础几何形状（圆、方、三角、线条等）和行业分类浏览，遇到绝妙的负空间或图形隐喻可直接右键保存进参考目录，非常适合 Logo 创意发散期训练抽象概括能力。
- ⭐ **[Brand Guidelines](https://brandguidelines.net/)**（`brandguidelines.net`）：专门汇集各国企业真实官方品牌规范文档的目录（收录了 Twitch、Instacart、Asana 等知名公司），涵盖可在线查看的网页版规范、PDF 手册与 Figma 指南文件。需要编写自己团队或客户的 Brand Book 时，直接在这里照着目录结构、网格安全区、禁用示例来搭框架，几乎不会漏项。
- ⭐ **[Rebrand Gallery](https://rebrand.gallery/)**（`rebrand.gallery`）：专注品牌升级与视觉重塑（Rebrand）的案例展馆，特色在于**高度重视品牌焕新 Reveal 视频与动态识别（Motion Branding）**——不仅看静态新标，还能直观感受一套品牌是如何通过字体动效、3D 质感与配乐完成气质转型的。
- ⭐ **[Deck Gallery](https://deck.gallery/)**（`deck.gallery`）：高质量演示文稿与品牌指南滑片库，里面既能翻到一线大厂的真实品牌指南（例如 Opera 品牌指南、Linear、OpenAI 等案例），也能一页页拆解顶级团队如何用极简版式讲清产品故事、数据图表与视觉规则，做重要汇报或融资 Deck 时参考价值极高。

### 4.2 品牌史料、改版评析与现代 Logo/Deck 补充

- **[Branding Style Guides](https://brandingstyleguides.com/)**（`brandingstyleguides.com`）：与 Brand Guidelines 互补的老牌免费目录，长期收录大量跨国企业、高校、非营利组织和公共机构的原始 PDF 品牌规范手册。
- **[Standards Manual](https://standardsmanual.com/)**（`standardsmanual.com`）：专门抢救、复刻并出版经典历史视觉规范手册（如 NASA 图形标准手册、纽约地铁导向标识系统）的独立出版方，想看工业级与公共系统级规范如何严谨到毫米级，必看。
- **[Brand New（UnderConsideration）](https://www.underconsideration.com/brandnew/)**（`underconsideration.com/brandnew`）：全球品牌改版评论界的风向标，专门针对各大商业公司与机构的新旧标识对比（Before / After）及延展物料做专业锐评，既看案例也学评价维度。
- **[Brand Archive](https://www.brandarchive.xyz/)**（`brandarchive.xyz`）：面向深度品牌研究的系统性案例库，单条案例会尽量收齐艺术指导、排版字体、色板及上百张延展应用，比只放几张效果图的画廊更立体。
- **[LogoArchive](https://www.logo-archive.org/)**（`logo-archive.org`）与 **[Logggos](https://www.logggos.club/)**（`logggos.club`）：LogoArchive 聚焦二十世纪中叶现代主义符号历史，并支持以图搜相似造型（Discover Similar）和自建情绪板；Logggos 则偏现代数字与科技初创标志，能按字标风格（衬线/无衬线/等宽/手写）与具体元素快速筛选。
- **[BP&O](https://bpando.org/)**（`bpando.org`）与 **[The Brand Identity](https://the-brandidentity.com/)**（`the-brandidentity.com`）：两大高质量独立品牌与包装印刷评论媒体，特别适合补充实体包装、印刷工艺、纸张纹理和工作室一线访谈。
- **[Pitch Deck Hunt](https://www.pitchdeckhunt.com/)**（`pitchdeckhunt.com`）与 **[Pitch Templates](https://pitch.com/templates)**（`pitch.com/templates`）：前者归档了大量创业公司不同融资轮次的真实路演文件，后者提供现代感极强的协作式演示模板，可和 Deck Gallery 搭配使用。

## 五、每日设计聚合、社媒帖子与灵感收集（Daily Feeds & Moodboards）

除了带着明确目标去垂直画廊找参考，平时保持敏锐度还需要**高信噪比、低算法垃圾**的日常订阅源与个人收集工具。

### 5.1 每日人工精选与真实社媒设计墙

- ⭐ **[Recent Design](https://recent.design/)**（`recent.design`）：每日人工筛选更新的设计精选聚合站（也是原人气网页画廊 Godly 演进迁移后的新平台）。它重点从 X/Twitter 上抓取一线设计师、Design Engineer 与独立开发团队发布的真实网页、界面动画和视觉探索，通过人工筛掉营销水帖并保留原作者链接，每天刷几分钟就能掌握前沿设计社区正在流行什么。
- ⭐ **[Posts Design](https://posts.design/)**（`posts.design`）：每日更新的**真实社交媒体传播视觉库**。和常规 UI 画廊不同，它专收科技品牌与初创团队在 X/Twitter、LinkedIn 真正发出来的产品发布卡片、数据里程碑海报、功能更新截图与 OG 分享图（例如 Vercel、Linear、Perplexity 等团队的宣发配图风格），自己做开源项目发布或版本更新海报时非常实用。

### 5.2 新生代设计社区与纯净情绪板工具

- **[Layers.to](https://layers.to/)**（`layers.to`）：面向数字产品与界面设计师的新一代作品分享社区，画面克制、UI 含量高，少有早年平台那种脱离落地的“飞机稿”感，适合看移动端组件与网页微创新。
- **[Savee](https://savee.it/)**（`savee.it`）与 **[Cosmos](https://www.cosmos.so/)**（`cosmos.so`）：目前大量视觉与产品设计师用来替代传统图站的纯净美学收集引擎，极少广告和噪声推荐，适合在平时零散刷图时把同风格案例收进自己的主题灵感板（Moodboard）。
- **[Are.na](https://www.are.na/)**（`are.na`）：没有点赞排行榜和流量算法的跨媒介知识/视觉连接工具，界面极简，适合做长期专题调研（如收集特定年代排版、工业仪表界面、装置艺术参考）。
- **[Sidebar](https://sidebar.io/)**（`sidebar.io`）与 **[Muzli](https://muz.li/)**（`muz.li`）：Sidebar 每个工作日精挑 5 条 UI/UX 与前端领域的好文章或好工具，适合当低负担晨读；Muzli 可作为浏览器新标签页聚合器，把多家灵感画廊收进同一屏。
- **[Dribbble](https://dribbble.com/)**（`dribbble.com`）与 **[Behance](https://www.behance.net/)**（`behance.net`）：老牌通用平台如今更适合作为补充——看局部视觉表现、插画和配色灵感去 Dribbble，看带完整调研、线框、设计推导过程的长案例复盘去 Behance。

## 六、渐变、Shader 背景、字体与图形素材库（Shaders, Fonts & Assets）

灵感到位后，落地阶段最常缺的是三样“原材料”：**不俗气的背景质感（渐变/Shader/纹理）、有性格且授权清晰的字体，以及干净的矢量图标与图形包**。

### 6.1 动态渐变、Shader 工具与买断制综合素材店

- ⭐ **[Grainient](https://grainient.supply/)**（`grainient.supply`）：专攻颗粒感（Grainy）与丝滑渐变背景的素材网站，不仅收录了上千张高分辨率噪点渐变与动态渐变背景，还自带 **Shader 渐变调参生成工具**。给深色或浅色 SaaS 首屏、卡片底座、发布会封面加一层克制的胶片噪点与流体渐变时，出图质感非常现代。
- ⭐ **[YouWorkForThem](https://www.youworkforthem.com/)**（`youworkforthem.com`）：非常经典且硬核的独立字体与视觉素材商店，主打**透明买断制、不捆绑按月订阅**，适合讨厌长期订阅付费的小团队与独立开发者。站内既有个性鲜明的现代商业字体（比如视频教程中常出镜的几何科技风格字体 Axicode），也有海量 Y2K 矢量形状包、抽象 3D、胶片纹理与品牌样机模板。

### 6.2 Shader 生成器、配色、开源字体与图标库补充

## 七、实战调用路线：不同场景怎么组合这批网站

书签收藏几十个容易吃灰，最有效的方式是按当前任务阶段**固定一套 4～5 站的短链路**：

1. **从零做一个独立产品 / 开源项目官网**
   - `A1 Gallery` / `Minimal Gallery` / `Saaspo` 选定 2 个对标版式 → `Supahero` + `Navbar Gallery` + `Footer.design` 分别敲定首屏、导航与页脚结构 → `Realtime Colors` + `Fontshare` 定配色与字体 → `Grainient` 或 `ShaderGradient` 补一层背景氛围 → `shadcn/ui` + `21st.dev` + `Lucide` + `SVGL` 写代码上线 → 用 `Posts Design` 的版式思路做一张发布日海报发社交平台。
2. **做移动端 App 改版或复杂 Web 交互优化**
   - `Mobbin` / `Page Flows` 先摸清主流产品完整状态流（含边界空状态与异常提示） → `60fps.design` + `Design Spells` 找具体转场曲线与手势反馈细节 → `Component Gallery` 核对跨大厂组件命名与键盘/无障碍规范 → `Motion` 或 `Rive` 落地动效。
3. **做品牌视觉升级、技术分享或路演演示文稿**
   - `Rebrand Gallery` + `Brand New` 看改版逻辑 → `Brand Guidelines` + `Branding Style Guides` 建一份规范文档大纲 → `Logobook` + `LogoArchive` + `Logggos` 找几何符号灵感 → `Deck Gallery` 对照大厂品牌手册与幻灯片排版做 PPT → 需要独特字体或 Y2K 矢量图形时去 `YouWorkForThem` 按单次买断采购，避免长期订阅负担。
4. **日常低成本保持审美输入（每天 5 分钟）**
   - 早上看一眼 `Recent Design`（一线设计师新品直出）和 `Sidebar`（5 条精选阅读），遇到击中灵感的画面顺手收进 `Savee` 或 `Cosmos` 的对应项目看板里，需要用时直接回翻，而不必在动工时临时抱佛脚。
